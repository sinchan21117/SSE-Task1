# while loop

## 1. while loop me ek entry controlled loop hai phele wo us entry ko condition me check karta hai agar shi hai toh fir use update karta hai value then fir condition check agar false hoti hai condition then we come out of loop.

## 2. syntax

while(condition){
    // code to be executed
}

## 3. example

int count = 1
while(count<=5>){
    cout<<count;
    count++;
}
